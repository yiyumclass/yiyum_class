# 상품명 기준

- 판매 상품명은 `products.title`을 기준으로 한다. 관리자 상품관리, 수강 방식 선택창, 결제 화면이 같은 이름을 사용한다.
- 수강 방식 선택창의 코드 기본 이름은 해당 상품이 조회되지 않을 때만 사용한다. 이 경우 구매 버튼은 비활성화한다.
- 세 멤버십이 공유하는 원본 강의명은 `courses.title`이다. 홈의 강의명과 공통 강의 소개·목록은 상품 등급명이 아니라 원본 강의명을 표시한다.
- 결제 알림톡의 승인 템플릿별 상품명은 별도 설정이다. 이 변경에서는 발송 로직과 템플릿을 수정하지 않는다.

## 기존 데이터 정렬

`supabase/migrations/20261005060000_align_membership_product_titles.sql`:

| 상품 slug | 기존 이름 | 정렬할 이름 |
| --- | --- | --- |
| sns-monetization | 이윰 SNS 수익화 클래스 | 베이직 클래스 |
| sns-monetization-feedback | 피드백 클래스 | 부스터 클래스 |
| sns-monetization-ultra | 초밀착 클래스 | 프리미엄 클래스 |

기존 이름과 정확히 일치하는 강의 상품만 변경한다. 관리자가 이미 다른 이름으로 변경한 상품은 덮어쓰지 않으며, 재실행해도 변경되지 않는다.
가격, 판매 상태, 상품 ID·slug, 원본 강의, 주문·수강권은 변경하지 않는다. 기존 상품 수정 트리거의 수정 시각·수정자·감사 로그 갱신은 그대로 수행된다.

## 적용 순서

1. 위 상품명 데이터 변경만 별도로 적용할 수 있도록 준비한다. 미배포 결제 보완 마이그레이션을 함께 실행하지 않는다.
2. 원본 강의명과 상품명을 구분하는 코드 변경을 배포한 뒤 위 마이그레이션을 적용한다.
3. 관리자 상품관리와 홈·상세의 수강 방식 선택창, 결제 화면에서 세 상품명을 확인한다. 공통 강의 소개는 `이윰 SNS 수익화 클래스`로 유지되어야 한다.

이 문서는 적용 절차이며 운영 DB에 적용되었다는 기록은 아니다.
